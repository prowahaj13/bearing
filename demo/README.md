# Demo Notes

This folder is reserved for demo assets, notes, and annotated walkthroughs. Use it for:

- onboarding videos or screenshots
- sample lead imports
- quick user journey walkthroughs
- presentation-ready examples

## Suggested demo flow

1. Select a goal such as Find clients.
2. Choose a category and refine the query with a keyword.
3. Open the People or Jobs search links.
4. Import a small lead list.
5. Review scores and update statuses.

The app is intentionally simple so a demo can focus on workflow value rather than infrastructure complexity.
