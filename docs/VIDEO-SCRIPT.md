# 60–90 second walkthrough script (record with Loom)

Record this yourself — a screen recording is the one artifact here that
has to visibly be you operating the real, deployed site. A script written
by anyone else and read verbatim tends to sound scripted; use this as a
checklist of beats to hit, not a word-for-word transcript.

1. **(0:00–0:10) What it is.** "This is Bearing — it builds targeted
   LinkedIn search links and tracks outreach, all client-side, no login
   required to use the free tier."
2. **(0:10–0:30) Core flow.** Pick a goal and category on the Find tab,
   show the generated search links and message. Click one link to show it
   actually opens LinkedIn's real search.
3. **(0:30–0:45) Leads tab.** Paste or load sample leads, show the score
   and status pipeline.
4. **(0:45–1:00) Pro tier.** Open Settings, show the license activation
   flow (use your own real license key here, not a placeholder — this is
   the moment a buyer checks whether the payment flow is real).
5. **(1:00–1:15) Ownership handoff.** Briefly show the GitHub repo
   structure and mention what's included in a sale (domain, accounts,
   code — whatever you decided in the listing checklist).
6. **(1:15–end) Sign-off.** State clearly what you're offering: e.g. "Full
   source, deployment config, and [accounts] for $X."

Keep it under 90 seconds — buyers skim these, and a long video reads as
padding rather than substance.
